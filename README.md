# survey-tally

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표(문항 / 유효 응답 / 평균 / 빈 응답 / 제외)를 보여 주는 설문 집계기입니다.

- `index.html` 파일 하나로 동작합니다. 브라우저로 열기만 하면 됩니다 (GitHub Pages에도 그대로 올릴 수 있습니다).
- 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않습니다.
- 붙여넣은 데이터는 브라우저 안에서만 계산하며, 어디로도 보내거나 저장하지 않습니다 (CSP로 바깥 요청도 막습니다).

## 집계 규칙

- 첫 열(응답번호)은 집계하지 않습니다.
- 앞뒤 공백을 지운 값이 `1`~`5`이면 **유효**, 비었거나 공백만 있으면 **빈 응답**, 그 밖의 값은 **제외**입니다.
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 셉니다. 남는 칸은 무시합니다.
- 평균은 유효 응답의 합 ÷ 유효 응답 수를 소수 셋째 자리에서 반올림해 둘째 자리까지 보여 줍니다. 유효가 0이면 `-`입니다.

자세한 내용은 [docs/PLAN.md](docs/PLAN.md)를 보세요.

## 시험

Node 18 이상에서, 설치할 것 없이:

```bash
npm test
```

계산 로직은 `index.html`의 `<script id="tally-core">`에 화면과 떼어 두었고, `tests/core.test.js`가 이 블록만 꺼내 DOM 없이 시험합니다. `tests/safety.test.js`는 외부 자원·전송·저장 API가 없는지 확인합니다.
