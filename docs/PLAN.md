# 설문 집계기 계획서

## 목표

엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표를 보여 주는 단일 페이지 `index.html`.

## 지켜야 할 조건

- 파일은 `index.html` 하나. 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않는다.
- 붙여넣은 데이터는 브라우저 밖으로 보내지 않고, 어디에도 저장하지 않는다.
  - `fetch`·`XMLHttpRequest`·`localStorage`·`sessionStorage`·`indexedDB`·쿠키를 쓰지 않는다.
  - CSP(`default-src 'none'`, `connect-src 'none'`, `form-action 'none'`)로 바깥 요청을 브라우저 차원에서도 막는다.
  - 입력칸에 `spellcheck="false"`, `autocomplete="off"`를 달아 맞춤법 검사 서비스로 내용이 넘어가지 않게 한다.
  - `<form>`을 쓰지 않으므로 제출로 인한 전송도 없다.
- 저장소 맨 위에 빈 `.nojekyll` 파일을 둔다 (GitHub Pages가 Jekyll 처리를 건너뛰도록).

## 집계 규칙

| 항목 | 규칙 |
|---|---|
| 입력 형식 | 엑셀 복사 형식: 칸은 탭, 줄은 줄바꿈(`\r\n` 또는 `\n`). 큰따옴표로 감싼 칸(칸 안 줄바꿈·탭)도 엑셀 방식대로 읽는다. |
| 머리글 | 첫 줄. 첫 열(응답번호)은 집계하지 않는다. 둘째 열부터가 문항이다. |
| 유효 | 앞뒤 공백을 지운 값이 `1` `2` `3` `4` `5` 중 하나 |
| 빈 응답 | 비었거나 공백만 있는 칸 |
| 제외 | 그 밖의 값 (예: `6`, `0`, `3.0`, `３`, `a`) |
| 모자란 칸 | 칸 수가 머리글보다 적은 줄은 모자란 칸을 빈 응답으로 센다 |
| 남는 칸 | 머리글보다 많은 칸은 해당 문항이 없으므로 무시한다 |
| 완전히 빈 줄 | 글자가 하나도 없는 줄(엑셀 복사 끝에 붙는 줄바꿈 등)은 응답으로 치지 않는다 |
| 평균 | 유효 응답의 합 ÷ 유효 응답 수, 소수 셋째 자리에서 반올림해 둘째 자리까지 (예: `3.00`, `2.35`). 유효가 0이면 `-` |

평균은 부동소수점 오차를 피하려고 정수 연산으로 반올림한다:
`round = floor((200 × 합 + 수) / (2 × 수))` → 이 값을 100으로 나눠 소수 둘째 자리까지 표시.

## 결과 표

열: **문항 / 유효 응답 / 평균 / 빈 응답 / 제외**. 행은 머리글 순서대로. 문항 이름이 비어 있으면 `(이름 없음, N열)`로 표시한다.
화면에는 반드시 `textContent`로 넣어 붙여넣은 값이 HTML로 해석되지 않게 한다.

## 구조

- `index.html`
  - `<script id="tally-core">`: 화면과 무관한 순수 함수(`parseTSV`, `classifyCell`, `formatAverage`, `tally`). DOM을 건드리지 않는다.
  - 두 번째 `<script>`: 화면 연결(입력 → `tally` → 표 그리기).
- `tests/core.test.js`: `index.html`에서 `tally-core` 스크립트를 꺼내 Node `vm`으로 실행하고 규칙을 시험.
- `tests/safety.test.js`: `index.html`에 외부 주소·저장/전송 API가 없고 CSP와 `.nojekyll`이 있는지 시험.
- 시험 실행: `node --test` (Node 18+, 설치할 것 없음).
